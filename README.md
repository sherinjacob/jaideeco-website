# jaideeco.com

Website for Jaidee & Co., a house of Thai-made brands.

Served by GitHub Pages from the `main` branch (root). The `CNAME` file sets the custom domain to jaideeco.com.

## Contact form

The form posts to FormSubmit (https://formsubmit.co) which emails each enquiry to jacob@jaideeco.com.
The first submission triggers a one-time activation email to that address; click the link in it to switch the form on.
If sending fails, the page offers a pre-filled email link instead.
